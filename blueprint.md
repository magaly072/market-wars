# **App Name**: Market Wars

## Core Features:

- Trading Battle Arena: A high-performance trading interface with live simulated price charts for assets like BTC, NVDA, and TSLA, featuring long/short trade execution with up to 50x leverage.
- Simulated Market Engine: A persistent system managing trade entry/exit logic, real-time P&L tracking, and leverage-adjusted margin calculations stored in the database.
- Competitive Tournament System: Functionality to join time-bound tournaments where users start with equal virtual capital and compete for prize pools based on final balance.
- AI Market Sentiment Tool: An AI-powered tool that analyzes simulated market trends and technical indicators to provide traders with real-time sentiment meters (Bullish/Bearish).
- Real-time Leaderboards: Instant updates of tournament rankings and overall user ROI, providing a social, competitive atmosphere using Firestore listeners.
- Interactive Performance Dashboard: Comprehensive user profile displaying total profit, win rate, tournament history, and detailed visual trade logs with profit/loss color coding.
- Achievement Rewards System: An XP and badge-based reward system that gamifies trading success by unlocking milestones like 'Tournament Champion'.

## Style Guidelines:

- Primary color: Electric Blue (#33C2FF) representing precision and high-tech fintech environments. It is vibrant to pop against the dark mode.
- Background color: Deep Obsidian (#101416), a heavily desaturated navy-black hue for a professional dark trading dashboard experience.
- Accent color: Neon Mint (#00FFAA), chosen to provide high-contrast for bullish indicators and success-based UI elements, following a technical neon aesthetic.
- Headline font: 'Space Grotesk', a geometric sans-serif that conveys a techy and scientific feel suitable for competitive arenas.
- Body font: 'Inter', used for its machined, objective look and exceptional readability for financial data across different screen sizes.
- Monospaced font: 'Source Code Pro', dedicated to displaying real-time price changes, trade parameters, and asset codes for an authentic terminal look.
- Mobile-first layout prioritizing rapid interaction. The trading arena features large-scale buttons for LONG/SHORT actions and a fixed chart view for quick analysis.
- Utilizes sophisticated transition effects such as pulse indicators for price updates and glowing border states for successful trades to enhance the 'esports' vibe.
